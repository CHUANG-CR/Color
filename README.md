    - [點此瀏覽](Duotone/README.md) — 運用兩種核心顏色，創造高對比、簡約且具強烈視覺衝擊的風格。

  * [點此瀏覽](Quadtone/README.md) — 使用四種顏色，適合需要多層次表達與複雜資訊的設計。
