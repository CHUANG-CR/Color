# Color 色卡專案 AI 執行規範

1. 作業範圍：只能讀取 Color 資料夾，嚴格禁止讀取其他資料夾或翻查歷史 git 紀錄。
2. 
3. 精準吸色與翻譯：讀取圖片像素抓取精準的 Hex 色碼，並上網搜尋顏色的中文名稱，格式完全照著 README.md 的排版勿隨意更動。
4. 
5. 檔名規則：我會將命名好的圖片放到對應數量顏色的資料夾，只須補上新的顏色。
6. 
7. 順序規則：請將所有圖片依照 README.md 的順序在檔名前面標上號碼，像 "1-Blue.png" 這樣（若尚未編號請自動補上，並同步更新 README.md 裡的圖片路徑）。
8. 
9. 批次處理：若未登記的新圖片超過 4 張，每次最多先處理前 3 張，完成後等待指示再繼續。
